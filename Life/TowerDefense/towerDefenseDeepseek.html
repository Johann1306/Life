Instructions du jeu

  • Objectif: Défendez votre base contre les vagues d'ennemis. Si votre base perd toutes ses vies, vous perdez.
  • Placement des tours: Cliquez sur une tour dans le magasin, puis cliquez sur une case vide du terrain pour la placer.
  • Amélioration des tours: Cliquez sur une tour placée pour voir ses options d'amélioration.
  • Système de recherche: Utilisez les points de recherche débloqués entre les vagues pour améliorer vos capacités globales.
  • Types d'ennemis:
    • Rapide: Se déplace vite mais a peu de vie
    • Résistant: Se déplace lentement mais a beaucoup de vie
    • Boss: Très résistant, apparaît toutes les 5 vagues
  • Conseils: Équilibrez votre stratégie entre différentes tours et améliorez-les régulièrement.
